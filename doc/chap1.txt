  [33X[0;0YThe purpose of the [5XIdPGroup[105X package is to implement identification functions
  for different [23Xp[123X-groups and thereby extend the functionality of the [5XSmallGrps[105X
  library.  Currently,  this includes an identification function for groups of
  order 512, as described in [ES26].[133X
  
  [33X[0;0YDetails  of  the  implementation  and  functionality  of  the identification
  functions   are  discussed  in  section  [14X2.1[114X.  Section  [14X2.2[114X  introduces  the
  definitions  of  (strong)  siblings  and includes functions to load all such
  sets of groups of certain order. Functions that were used to calculate these
  lists of groups and which can be used to calculate them for different orders
  can  be  found  in section [14X2.3[114X. Finally, section [14X2.4[114X describes all functions
  that  were  used  to  build  the search tree in the described identification
  routine and which can be used to build other such trees.[133X
