1 Introduction

The purpose of the IdPGroup package is to implement identification functions for different \(p\)-groups and thereby extend the functionality of the SmallGrps library. Currently, this includes an identification function for groups of order 512, as described in [ES26].

Details of the implementation and functionality of the identification functions are discussed in section 2.1. Section 2.2 introduces the definitions of (strong) siblings and includes functions to load all such sets of groups of certain order. Functions that were used to calculate these lists of groups and which can be used to calculate them for different orders can be found in section 2.3. Finally, section 2.4 describes all functions that were used to build the search tree in the described identification routine and which can be used to build other such trees.
