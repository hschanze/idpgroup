  [33X[0;0YThis chapter lists all functions contained in the [5XIdPGroup[105X package.[133X
  
  
  [1X2.1 [33X[0;0YIdentifying groups via a search tree[133X[101X
  
  [33X[0;0YThis  section  briefly describes the functions and variables of this package
  associated  to the identification of an arbitrary group of order 512 via the
  search  tree  [2XID_GROUP_512_TREE[102X ([14X2.1-2[114X). When saying 'identify a group [22XG[122X' we
  want to find an [13Xid[113X such that [10XSmallGroup(512, id)[110X is isomorphic to [22XG[122X.[133X
  
  [33X[0;0YThe used tree is implement as a nested record with the following components:[133X
  
  [30X    [33X[0;6Y"fp":  a  list  of integers, each being the encoded fingerprint of the
        group  resulting from the specific test performed at the current level
        of  the  identification  routine. Each integer is gained from appyling
        [2XIdPGroup_Pack[102X ([14X2.5-1[114X) to the fingerprint.[133X
  
  [30X    [33X[0;6Y"next":  a list comprised of the resprective subbranches corresponding
        to  the fingerprints in "fp". This is either a list of ids or a branch
        implemented as a record itself.[133X
  
  [33X[0;0YDepending  on  the  level  each  record  also  has  one of the following two
  components:[133X
  
  [30X    [33X[0;6Y"test":  a  string  that indicates which test was used via [2XTestOnGroup[102X
        ([14X2.5-5[114X) to create the listed fingerprints.[133X
  
  [30X    [33X[0;6Y"desc":  a list of integers that encode a description of the performed
        test using [10XEvalFpCoc[110X.[133X
  
  [33X[0;0YThe  first  levels of [2XID_GROUP_512_TREE[102X ([14X2.1-2[114X) try to distinguish groups by
  the following invariants:[133X
  
  [30X    [33X[0;6YThe rank of the group.[133X
  
  [30X    [33X[0;6YThe collected orders of all elements of the group.[133X
  
  [30X    [33X[0;6YThe  numbers  of  conjugacy  classes of each length and representative
        order (the order of the elements in the class) of the group.[133X
  
  [30X    [33X[0;6YThe  isomorphism type of the parent of the group, i.e. the quotient of
        the  group and the smallest non-trivial element of the lower-[23Xp[123X-central
        series.[133X
  
  [30X    [33X[0;6YThe  abelian invarants, i.e. the isomorphism types of the quotients of
        the derived series.[133X
  
  [30X    [33X[0;6YThe  cycle  structure  of  the permutations induced on all clusters of
        conjugacy classes of same length and representative order by the power
        map [23Xx\mapsto x^3[123X.[133X
  
  [33X[0;0YIf  necessary  these  invariants  are  followed by invaraints resulting from
  tests evaluated on partitions of [22XG[122X.[133X
  
  [33X[0;0YThe  initial  partition  is  made of the conjugacy classes of [22XG[122X grouped such
  that  conjugacy  classes  of  the  same length and same representative order
  belong  to the same partitioning subset. The results of [10XEvalFpCoc[110X applied to
  a  partition  give the invaraints used to distinguish groups in these levels
  of  the search tree. The exact behaviour is determined by the content of the
  component  "desc".  After  the  evaluation  of  each  test, the partition is
  refined according to the result of [10XEvalFpCoc[110X.[133X
  
  [33X[0;0YIf  the  preceding  invaraints  do not lead to a single group, the following
  (more time consuming) invaraints are calculated.[133X
  
  [30X    [33X[0;6YThe  isomorphism  types of the non-trivial factors formed by the group
        and   elements   of   the   smallest   non-trivial   element   of  the
        lower-p-central series.[133X
  
  [30X    [33X[0;6YThe  isomorphism  types of the non-trivial factors formed by the group
        and elements of the center.[133X
  
  [30X    [33X[0;6YThe isomorphism types of all maximal subgroups.[133X
  
  [33X[0;0YRemaining  are 139 pairs and 1 triplet of groups of unidentified groups. All
  these groups are distinguished by a random isomorphism test. That is done by
  selecting  random  elements  from  predefined clusters of conjugacy classes,
  that were used and potentially refined before, until these elements generate
  the  group.  This  list  of  generators  is  then turned into a [10Xpcgs[110X and the
  presentation  encoded  into  an  integer  by the funtion [10XCodeGenerators[110X. The
  resulting   integer   modulo  99661  is  then  compared  with  precalculated
  fingerprints  of the candidate groups. If none of the fingerprints coincides
  the  process  is  repeated. Thus the runtime of the identification for these
  groups is not constant.[133X

  [1X2.2 [33X[0;0YLoading (strong) siblings[133X[101X
  
  [33X[0;0YThis  section  describes  the  functions used to load precalculated lists of
  (strong) siblings, i.e. groups that fulfil the following definitions:[133X
  
  [30X    [33X[0;6Y[13Xsubgroup-equivalent  groups[113X  are  groups  with a bijection between the
        sets of proper subgroups s.t. preimage and image are isomorphic,[133X
  
  [30X    [33X[0;6Y[13Xfactor-equivalent  groups[113X are groups with a bijection between the sets
        of proper factors s.t. preimage and image are isomorphic,[133X
  
  [30X    [33X[0;6Y[13Xsiblings[113X   are  subgroup-  and  factor-equivalent  groups,  where  the
        bijection of proper subgroups preservs conjugacy and maps the Frattini
        subgroup,   lower   and  upper  central  series  onto  the  respective
        counterparts,[133X
  
  [30X    [33X[0;6Y[13Xstrong siblings[113X are siblings that are also Brauer Pairs.[133X
  
  [33X[0;0YAll  (strong)  siblings  of  orders  dividing 512 together with some trivial
  cases  are  implemented  in  this  package and are callable by the following
  functions.[133X
  
  [1X2.2-1 SiblingsIds[101X
  
  [33X[1;0Y[29X[2XSiblingsIds[102X( [3Xorder[103X[, [3Xindices[103X] ) [32X function[133X
  [6XReturns:[106X  [33X[0;10YA list of lists of ids of siblings of size [3Xorder[103X.[133X
  
  [33X[0;0YLoads  and  returns  a  list  of ids of siblings of size [3Xorder[103X if available.
  Currently available sizes are:[133X
  
  [30X    [33X[0;6Yall orders of the form [23Xp\,q[123X for [23Xp[123X and [23Xq[123X primes,[133X
  
  [30X    [33X[0;6Yall powers of two smaller than [23X2^9[123X[133X
  
  [30X    [33X[0;6Yall powers of three smaller than [23X3^5[123X[133X
  
  [30X    [33X[0;6Yall powers of a prime smaller than [23Xp^4 [123X[133X
  
  [30X    [33X[0;6Yall products of two powers and[133X
  
  [30X    [33X[0;6Yall  orders  smaller  than 255 except 60, 120, 160, 168, 180, 189, 192
        and 240.[133X
  
  [33X[0;0YIf  no  list is available for the provided order [10Xfail[110X is returned. If a list
  [3Xindices[103X is given, only the respective entries are returned.[133X
  
  [4X[32X  Example  [32X[104X

  [1X2.4 [33X[0;0YTable of bins of groups[133X[101X

  [1X2.4-1 TableOfGroupInvariants[101X
  
  [33X[1;0Y[29X[2XTableOfGroupInvariants[102X( [3XBins[103X, [3Xorder[103X ) [32X function[133X
  [6XReturns:[106X  [33X[0;10YA list of records.[133X
  
  [33X[0;0YCalculates some invariants and properties for the groups of order [3Xorder[103X with
  ids in lists of [3Xbins[103X. If the invariants are equal for all groups of a bin, a
  record listing all information is added to the returned list. The calculated
  invariants are:[133X
  
  [30X    [33X[0;6Ythe rank of the groups,[133X
  
  [30X    [33X[0;6Ythe [23Xp[123X-class of the groups,[133X
  
  [30X    [33X[0;6Ythe size of the groups of automorphisms.[133X
  
  [33X[0;0YFurthermore the following properties are examined for the groups of a bin:[133X
  
  [30X    [33X[0;6YAre  the groups outer-automorphism-equivaleant, i.e. are the groups of
        outer-automorphism isomorphic?[133X
  
  [30X    [33X[0;6YAre the groups isoclinic?[133X
  
  [30X    [33X[0;6YAre  the  groups a modular isomorphic pair (MIP), i.e. are their group
        rings over a field of characteristic p isomorphic?[133X
  
  [33X[0;0YThe last two properties are not examined and left as an empty string in this
  function,   but   can   be   filled   via  [2XDetermineMIPInTable[102X  ([14X2.4-2[114X)  and
  [2XDetermineIsoclinicInTable[102X ([14X2.4-3[114X).[133X
  
  [4X[32X  Example  [32X[104X
    [4X[25Xgap>[125X [27XBins := StrongSiblingsIds(512, [1, 5, 14]);[127X[104X
    [4X[28X[ [ 1364, 1368 ], [ 1680, 1681 ], [ 15826, 15827 ] ][128X[104X
    [4X[25Xgap>[125X [27XTableOfGroupInvariants(Bins, 512);[127X[104X

    [4X[28X       isoclinic := "",  mip := "", pclass := 5, rank := 2 ),[128X[104X
    [4X[28X rec( OutEqv := "yes", SizeAut := 16384, ids := [ 1680, 1681 ],[128X[104X
    [4X[28X      isoclinic := "", mip := "", pclass := 5, rank := 2 ),[128X[104X
    [4X[28X rec( OutEqv := "no", SizeAut := 65536, ids := [ 15826, 15827 ],[128X[104X
    [4X[28X      isoclinic := "", mip := "", pclass := 3, rank := 3 ) ][128X[104X

  [1X2.4-2 DetermineMIPInTable[101X

  [6XReturns:[106X  [33X[0;10YA list of records.[133X

  [1X2.5 [33X[0;0YFunctions for building a search tree[133X[101X
  
  [33X[0;0YThis  section  describes all functions and variables connected to building a
  search  tree that can be used with [2XIdGroup512[102X ([14X2.1-1[114X) to identify groups via
  implemented invariants.[133X
  
  [33X[0;0YIn  short  this is done be initializing a tree via calling [2XTestOnClusterList[102X
  ([14X2.5-6[114X)  with a selected test on a list of (lists of) ids of groups of given
  order and then iteratnig the following three steps[133X
  
  [30X    [33X[0;6YCollecting the clusters of the curent tree via [2XClusterList[102X ([14X2.5-4[114X),[133X
  
  [30X    [33X[0;6YPerforming  a  choosen  test  on  these clusters via [2XTestOnClusterList[102X
        ([14X2.5-6[114X),[133X
  
  [30X    [33X[0;6YExtending  the  tree with these test results via [2XAddClusterTestResults[102X
        ([14X2.5-7[114X).[133X
  
  [33X[0;0YA   very   effective   set   of   invaraints  can  be  obtained  by  calling
  [2XCocTestOnClusterList[102X  ([14X2.5-13[114X)  in the second step. This should only be done
  when the groups of each provided cluster yields the same value when the test
  [10XCocList[110X  is  applied. Furthermore these invaraints should be used for as few
  as  possible  clusters since [2XCocTestOnClusterList[102X ([14X2.5-13[114X) includes a search
  for suitable parameters than can take quite some time.[133X

  [1X2.5-9 FindParametersForCocTest[101X

  conjugacy  classes  in  [3Xcoc[103X  results in at least two different values. If no

  parameters  that  alter  [3XCoc[103X  until  either a suitable list of parameters is
  found  or  [3Xit[103X is equal to [3Xmaxit[103X. The parameters of the current iteration are
  provided  in the list [3Xparalist[103X. If the function is initialized with [3Xit[103X=0, it
  only  returns a list of parameters that alter the clusters in [3XCoc[103X. Depending
